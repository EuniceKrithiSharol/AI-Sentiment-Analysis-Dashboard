# Sentiment Analysis Dataset

This project analyzes text data to identify sentiment.

## Supported Text Sources

The application can analyze:

- Customer reviews
- Product feedback
- Survey responses
- Social media comments
- User feedback
- General text

## Sentiment Classes

The system classifies text as:

- Positive
- Negative
- Neutral

## CSV Usage

Users can upload any CSV file containing text.

The text column can be selected directly in the dashboard.
